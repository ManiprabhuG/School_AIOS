# Crud.md

# Objective

Every management module in the School ERP must have a complete CRUD (Create, Read, Update, Delete) system.

No module should contain hardcoded or static data.

All information must be entered, edited, deleted, searched, imported, and exported by the user through forms.

Every module should support database operations.
