# Root Cause Investigation

Check for the following issues:

---

## Frontend Only Deletion

Verify whether the delete action only removes records from local state.

Example:

setState()

filter()

local array deletion

without calling API.

---

## API Failure

Verify:

Delete API called?

Correct endpoint used?

Correct ID passed?

API returning success incorrectly?

---

## Database Failure

Verify:

Delete query executed?

Delete transaction committed?

Rollback occurring?

Soft Delete misconfigured?

Hard Delete misconfigured?

---

## Cache Issues

Check:

React Query

SWR

Redux

Context API

Browser Cache

Session Storage

Local Storage

Stale Cache

Revalidation Problems

---

## Data Source Issues

Check whether:

UI loads data from API

or

UI loads data from hardcoded arrays

or

UI loads data from seed files

or

UI loads data from local storage

---

## Refresh Issue

Investigate why:

Refresh

↓

Old records return

Possible causes:

- API reads wrong table
- Delete not persisted
- Cache restored
- Demo data reloads
- Seed process reruns
- Database transaction fails

Identify exact root causes.
